# Voice AI Platform

Production-grade Voice AI Platform for healthcare appointment scheduling.

## Features

- Real-time voice processing (VAD → ASR → LLM → TTS)
- Multi-agent architecture (Inbound, Outbound, Payer)
- HIPAA-compliant audit logging
- WebRTC and Twilio integration

## Quick Start
```bash
# Install
pip install -e .

# Run demo
python scripts/run_webrtc_demo.py
```
